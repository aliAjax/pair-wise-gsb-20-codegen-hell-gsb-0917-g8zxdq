# hxwl-06 显微镜玻片观察

可追溯的样本、多倍率视野与染色观察记录库

## 技术栈

React + Vite + TypeScript + CSS，数据持久化于浏览器 localStorage

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 功能

- 首次打开内置三条示例：洋葱表皮、人血涂片、草履虫
- 新建观察必填：样本名称、样本类型、染色方式、放大倍数、重点结构
- 放大倍数低于 400x 时，细胞核不允许标记为“已确认”
- 染色方式与样本类型不匹配时阻止保存，并提示具体原因
- 每条记录可标记“待复看”；复看提交后覆盖当前结论
- 上一版的保存时间与完整内容保留在版本时间线中，刷新后仍可追溯
- 按样本类型与复看状态筛选；可一键恢复内置示例
