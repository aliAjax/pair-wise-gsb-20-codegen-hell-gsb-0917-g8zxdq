# hxwl-06 显微镜玻片观察

样本、多倍率视野与染色观察记录库

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 功能

- 首次打开自动载入洋葱表皮、人血涂片、草履虫三条示例记录（localStorage 持久化，刷新不丢）
- 新增观察必填样本类型、染色方式、放大倍数、重点结构，缺项阻止保存
- 放大倍数低于 400x 时，细胞核不能标记为已确认
- 染色方式与样本类型不匹配时阻止保存，并给出该类型可用的染色方式
- 每条记录可标记复看：新结论覆盖当前版本，旧版本连同保存时间与内容进入历史
- 每条记录可展开变更追溯，查看全部历史版本；支持导出 JSON 摘要
- 按样本类型筛选、领域指标看板（样本数 / 视野记录 / 染色方法 / 重点结构）
